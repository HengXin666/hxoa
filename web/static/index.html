公网隧道-

AI 通过这个地址连到你的机器。cloudflared 不用自己装, 需要时会自动下载。

在 Cloudflare 后台 → My Profile → API Tokens 创建令牌, 权限: Account · Cloudflare Tunnel · Edit, Zone · DNS · Edit, Zone · Zone · Read。hxoad 会自动建隧道, 写 DNS, 启动 cloudflared; 这个 API 令牌只用一次, 不会保存。

在 Zero Trust → Networks → Tunnels 新建隧道, Public hostname 指向 http://127.0.0.1:7070, 复制安装命令 (或其中的 token) 粘贴到这里。
